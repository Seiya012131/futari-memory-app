ふたりのポケふた冒険｜完全版

追加した機能
・GPS取得前：実物画像をぼかし、シルエット風にロック
・GPS取得後：公式のポケふたデザインが鮮明に解放
・取得時：拡大・回転・紙吹雪の図鑑登録演出
・図鑑番号と登場ポケモンを表示
・PWA対応：HTTPSで公開後、スマホのホーム画面へ追加可能
・基本画面はオフライン対応
・ミッション、メッセージ、エンディング写真・文章は設定画面で編集可能

重要
・GPSはブラウザの仕様上、HTTPSで公開したURLから使用してください。
・ポケふた画像はポケモンローカルActs公式サイトの画像URLを表示しています。
・初回表示にはインターネット接続が必要です。表示後はブラウザにキャッシュされる場合があります。
・スタンプ、旅行写真、旅日記は使用端末内に保存され、別端末には自動同期されません。
・まずは成矢さんのスマホ1台をメイン端末にするのがおすすめです。

開き方
1. ZIPを展開
2. 確認だけならindex.htmlを開く
3. GPSを含む本番利用は、フォルダ一式をNetlify等へアップロード
4. iPhoneではSafariの共有→ホーム画面に追加
