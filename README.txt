YUNO NOTE｜最終目標デザイン版

デザイン方針
・白、アイボリー、ベージュを主役にした上品な配色
・モンスターボール、図鑑、マップなどポケモンらしい体験
・キャラクターを過度に並べず、大人っぽさを維持
・未取得時はポケふた画像とポケモン名を完全非表示
・取得後にのみポケふた画像、名称、写真追加を解放

主な機能
・GPS150m以内でポケふた取得
・取得演出
・ポケふた図鑑
・宮崎マップ
・写真アルバム
・コンプリート後の手紙
・テストモード
・以前の進捗データの引き継ぎ
・PWA対応

GitHubへの更新方法
1. ZIPを展開
2. リポジトリで「ファイルを追加」→「ファイルをアップロード」
3. 4ファイルをすべて上書き
4. Commit changes
5. Netlifyのデプロイ後、スマホで再読み込み
