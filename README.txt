YUNO NOTE｜最終仕上げ版

今回の反映内容

1. ホーム
・指定された完成イメージから青島のイラストをアプリ用素材として切り出し
・青島カードの丸画像を写真風からイラスト風へ変更
・ピカチュウ、ポッチャマ、イーブイも完成イメージと同じ柔らかいイラスト調へ統一

2. ポケふた取得
・取得画面にイラスト調のピカチュウ、ポッチャマを表示
・取得した場所ごとにピカチュウ、イーブイ、ポッチャマが交代で登場
・ポケふた本体は取得時に初めて公開

3. マップ
・完成イメージの宮崎イラストマップをアプリ内素材として使用
・下部のスポットリストを廃止
・地図上の9個のモンスターボールを直接タップできる透明ボタンを配置
・タップすると該当する図鑑詳細を表示
・取得済みスポットにはチェック表示

4. 図鑑・全体
・キャラクター素材をすべて同じイラスト調へ変更
・図鑑カードの質感と光の表現を調整
・外部から画像を貼ったように見えないよう、ローカル画像としてアプリへ同梱
・主要な文章の編集、GPS、アルバム、手紙自動表示は維持
