YUNO NOTE｜宮崎ポケふたの旅 Ver.1.0 完成版

デザイン
・提供された最終目標画像を基準に全面リデザイン
・白、アイボリー、ベージュ中心のやさしい配色
・Kiwi Maru / Zen Maru Gothicのかわいい文字
・ピカチュウ、ポッチャマ、イーブイをUI装飾として自然に配置
・花、キラキラ、丸み、余白を全画面で統一
・青島カードとピカチュウが重ならないよう配置を調整

宮崎マップ
・南北に長い宮崎県の輪郭を再設計
・日向灘、九州山地、主要地域、山、ヤシ、方位装飾を追加
・9か所のポケふたを県内の位置関係に合わせて手動配置
・すべてのピンが県の輪郭内に収まるよう調整

機能
・GPS150m以内で取得
・未取得画像とポケモン名は完全シークレット
・取得演出、図鑑、写真アルバム
・9個取得時に手紙が自動到着
・ホームにも手紙の存在を表示
・主要文言を成矢専用設定から編集可能
・過去バージョンの進捗を可能な範囲で引き継ぎ
・PWA対応

GitHub更新方法
1. ZIPを展開
2. GitHubのリポジトリを開く
3. ファイルを追加 → ファイルをアップロード
4. 中の5ファイルをすべて上書き
5. Commit changes
6. Netlifyのデプロイ完了後、スマホでタブを閉じて再度開く

実機確認
・位置情報を許可
・設定画面のテストモードが本番前にOFFであること
・9個目取得後の手紙自動表示
・写真保存
