YUNO NOTE｜宮崎ポケふたの旅 改良完成版

今回の追加・修正
1. アプリ内の主要な文言を「成矢専用設定 → 言葉」から編集可能
   オープニング、ホーム、旅先、ミッション、各画面タイトル、
   手紙予告、手紙到着画面、フッターなど30項目を編集できます。

2. 9つ目のポケふた取得後
   取得演出を閉じると「ゆのさんへ。成矢からお手紙です。」が自動表示されます。
   ホームにも手紙の存在と残り個数を常時表示します。

3. ポケモン要素
   ピカチュウ、ポッチャマ、イーブイをホーム・図鑑・手紙画面に配置。
   ポケふた、モンスターボール、図鑑登録の世界観も維持しています。
   本アプリは個人利用を想定したファンメイド作品です。

4. 宮崎県マップ
   国土地理院の宮崎県図を参考に、県の南北に長い輪郭、
   日向灘側の海岸線、主要地域の位置関係を描き直しました。
   ポケふたのピンは緯度経度から自動配置しています。

地図参考
・国土地理院「45 宮崎県」
・国土交通省 国土数値情報 行政区域データ
